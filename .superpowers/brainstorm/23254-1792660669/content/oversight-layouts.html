Three layouts for the main aiman screen. Each session has a to-do list you can see and edit. Click the one closest to what you want; mixing them is fine, just say so in the terminal.

The list you have today, with each session's to-do progress added. The selected session's to-do list and last message show on the right. Edit to-dos and type a prompt without attaching.
